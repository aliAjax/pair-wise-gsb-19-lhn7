# hxwl-05 观赏鱼寄养登记台

假期观赏鱼寄养登记：顾客与鱼只登记、寄养缸分配、超期计费、回取结算与寄养档案查询。

## 技术栈

React + Vite + TypeScript + CSS

## 本地运行

```bash
npm install
npm run dev
```

开发端口：5105

## 功能

- 寄养登记：记录顾客、电话、品种、鱼只数量、原缸水温、水质类型与计划寄养天数
- 自动分缸：按水质类型与剩余空间匹配寄养缸（同水质、空位足够、优先紧凑缸位）；没有合适位置时留在待安排
- 寄养缸看板：各缸水质类型、水温、占用/空闲位置与在养清单
- 位置释放：顾客提前取消或回取结算后立即释放寄养位，待安排订单按登记顺序自动入缸
- 超期计费：寄养费 ¥5/鱼/天，超期每天追加 ¥3/鱼，超期订单自动标记
- 回取结算：登记健康状态与备注，按实际寄养天数 + 超期追加完成结算
- 寄养档案：按顾客姓名或电话查询全部寄养经历与累计消费
- 数据持久化：寄养单保存在 localStorage，刷新不丢失
