# hxwl-05 观赏鱼寄养登记台

假期顾客送养观赏鱼的前台登记与结算：按水质和空位自动分配寄养缸、超期自动计费、回取可追溯。

## 技术栈

React + Vite + TypeScript + CSS（数据保存在浏览器 localStorage）

## 本地运行

```bash
npm install
npm run dev
```

开发端口：5105

## 功能

- **寄养登记**：记录顾客与电话、鱼只品种/数量、水质类型、原缸水温、登记日与约定回取日
- **自动选缸**：按水质类型匹配寄养缸，在剩余位置足够的缸中选空位最贴合的（best-fit）；
  没有合适缸位时自动进入「待安排」，不计费不占缸位，缸位释放后可一键重新匹配
- **缸位占用**：入缸立即占用位置；顾客提前取消或到店回取结算后立即释放，寄养缸看板实时刷新
- **超期计费**：在缸费用 = 鱼数 × 在缸天数 × 缸日单价；超期每天每尾追加 2 元，费用随日期实时预估
- **回取结算**：登记回取健康状态（良好/一般需观察/状态不佳）与备注，自动结算基础费+超期费
- **寄养经历**：按顾客姓名、电话或品种检索已回取/已取消的寄养单，含费用明细与完整操作流水
- 首页指标卡展示待安排、在缸单、缸位占用与超期单数量；内置示例数据，可一键恢复
